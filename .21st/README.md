# Nanashi design sources

Obsidian is a native SwiftUI adaptation of the retrieved Graphite Mono theme and 20 new distinct 21st component designs. Nine earlier source primitives remain in use. Source IDs, authors, bundles, destination files and material changes are recorded in `sources.json`; build and native QA evidence belongs in `design.json`.

The reference TSX is not shipped as an embedded web app. Real routes, data, validation, offline behavior and original storage identifiers are retained. The upstream NOOP license and credits remain intact.

Native adaptations replace browser hover, DOM motion and library dependencies with SwiftUI controls, static vector layers and finite springs. Semantic health colors are retained. The calendar shows real daily recovery rather than summing scores as transaction counts. Large text, focus, enabled states and native keyboard handling are preserved.

Shadcn Space and Kuratli source notices are saved in `licenses/` and included in the StrandDesign resource bundle. The caches retain the actual component and demo code used for the adaptations.

Current verification: final iOS Simulator, signed iOS and macOS builds succeeded. The design suite passed 134 tests, the decimal parser 68 cases, local search 8 checks and calendar selection 12 checks. Fourteen actual Obsidian screenshots were reviewed in light/dark appearances, including large text and honest empty states. Scope and limits are recorded in `design.json`; GUI interactions and iOS16 runtime appearance are not claimed as verified. Nanashi 12.1.0 (build 437) was installed and normally launched on iPhone13; its process was confirmed still running. Earlier Amber QA is historical only (`history/amber-final.json`).

The violet palette was rejected by the user. Obsidian adopts [Graphite Mono](https://21st.dev/@serafimcloud/themes/graphite-mono): neutral backgrounds, silver selection on the graphite dock, and source foreground pairs. Medical status colors retain their meanings. The theme is excluded from the count of 20 new components.
