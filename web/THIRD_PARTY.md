## 21st design adaptations

These public component sources were retrieved with the official 21st CLI on 2026-11-12 and adapted to Nanashi's established Cold Glass tokens. The site visibly links back to each author and component. No catalogue screenshots or videos are republished.

- [Glass Card — @educalvolpz](https://21st.dev/@educalvolpz/components/glass-card), component 28259: frosted body, polished rim and layered shadow. The site uses static CSS instead of displacement and pointer tracking.
- [Glass Button — @jahed](https://21st.dev/@jahed/components/glass-button), component 4922: pill geometry and directional reflective edge. The site uses static CSS and native anchors instead of injected CSS/CVA.
- [Pill Morph Tabs — @ruixen.ui](https://21st.dev/@ruixen.ui/components/pill-morph-tabs), component 7878: selected glass plate and labelled tabs. The site uses CSS transitions and roving keyboard focus instead of the motion runtime.

The palette continues the native project's [Harbor Blue theme](https://21st.dev/community/themes/harbor-blue). Component metadata returned by the registry did not include individual license fields; no MIT license is asserted for these authors. The original authors retain their rights. See the [21st terms](https://docs.21st.dev/terms), including source attribution requirements.

The app icon belongs to the existing Nanashi identity. The phone preview is a local simulator capture with synthetic data, not marketplace media or a private health export.
