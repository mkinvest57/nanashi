# Nanashi public website

The public installation site continues the native Cold Glass identity. Harbor Blue provides the navy canvas, icy blue action color and neutral glass surfaces. The existing native icon and a synthetic simulator capture connect the site to the actual product.

The page has one primary job: guide the visitor to a valid phone installation. Phone platform detection selects an initial guide and never infers installed apps. Returning iPhone users get one direct SideStore install action; first-time setup is a separate choice with progressive steps. Android exposes one download action. Desktop visitors receive a compact QR and a copyable URL, with no SideStore protocol links. Source addition, raw package files, checksums and renewal details stay in collapsed help. Unpublished, unavailable and invalid release states never display a fabricated download. The optional Firebase read concerns public release metadata only.

Shared primitives are GlassPanel, GlassLink and PlatformTabs. They adapt actual retrieved 21st sources, with visible source/author links in the page and exact references in README.md. Optical layers are static; only finite control feedback animates. There is no pointer-following runtime, WebGL, canvas loop or external font request.

Accessibility: native links/buttons/details, roving keyboard tab focus, visible focus rings, 44-pixel targets, rem text, reduced-motion and reduced-transparency fallbacks. Mobile has one-column installation and feature layouts. Color and spacing roles are centralized in src/tokens.css.

No private data, 21st preview media, invented testimonials, fabricated release files or promise of permanent Apple signatures is included.

The installation action only opens SideStore; its confirmation and optional widget choice remain explicit. After-click guidance never claims success. Unknown instance/platform state does not trigger an app launch, and Android visitors switching to the iPhone guide receive device guidance instead of an unsupported protocol URI. The existing daily renewal automation and native data are outside this website change.

First-time setup now has a dedicated /installation-sidestore route: one active step, six freely revisitable stages, direct Mac/Windows installers, phone handoff QR, and explicit browser-local confirmations. Download links leave for official files or the App Store only; instructions remain in the Nanashi guide. No account data is collected.
